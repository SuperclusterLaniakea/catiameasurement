# CATIA 零件测量与提取（自动化）

一套用于 **CATIA V5** 的零件/装配体测量与信息提取工具，支持：

- 几何测量：体积、表面积、质量（重量）、包络体（AABB 长宽高）
- 信息提取：用户自定义参数、几何图形集参数、三维标注（GD&T 等）文本
- 截图：零件整机截图、三维标注逐个截图（写入 Excel）
- 输出：文本报告 `测量结果.txt` + 结构化 `results.json` + 多页 Excel `测量结果.xlsx`

提供两种使用方式：

1. **Python 自动化**（`measure_catia.py` + 可选 GUI `measure_gui.py`）—— 支持批量、装配体、Excel 报告，**主工具**。
2. **VBA 宏**（`MeasurePart.CATScript`）—— 在 CATIA 内手动运行，仅测单个零件，适合无 Python 环境时快速测一个件。

> 运行 Python 工具**必须**在本机装有 CATIA V5（含 SPA 许可）的环境；本仓库的开发机当前未安装 CATIA，故测量需在你装有 CATIA 的机器上执行。

## 一、Python 自动化（主工具）

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 基本用法

```bash
# 测量 test/ 下所有 CATPart/CATProduct, 生成 测量结果.txt / results.json / 测量结果.xlsx
python measure_catia.py --dir test

# 指定材料密度(默认 7.85 g/cm3 钢); 零件已赋材质时自动采用材质密度
python measure_catia.py --dir test --density 2.70

# 打开图形界面(复选框选择提取内容)
python measure_catia.py --gui
# 或: python measure_gui.py
```

### 3. 命令行参数

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--dir` | 要测量的目录 | `test` |
| `--density` | 密度 g/cm³（零件无材质时采用） | `7.85` |
| `--out` | 文本报告路径 | `<dir>/测量结果.txt` |
| `--excel` | Excel 路径 | `<dir>/测量结果.xlsx` |
| `--json` | 中间数据路径 | `<dir>/results.json` |
| `--shots` | 三维标注逐个截图并写入 Excel（需先运行一次主程序生成 results.json） | 关 |
| `--gui` | 打开图形界面 | 关 |

### 4. 提取内容

- **几何测量**：体积（m³）/表面积（m²）/质量（kg）/重量（N）/包络体（mm）。
  - 体积/表面积：SPAWorkbench.Measurable；整零件失败则遍历各几何体累加。
  - 质量 = 体积 × 密度；重量 = 质量 × 9.80665。
  - **密度自动检测**：零件已赋材质时读取材质密度（kg/m³ → g/cm³）；仅当 >1000 才采信，否则用 `--density`。
  - **包络体**：默认用 `Measurable.GetBoundingBox`（按几何体并集，可靠）；不可用时回退"远置平面法"（±1e6 mm 处建临时平面，用 `GetMinimumDistance` 反推 AABB，测完删除）。
- **用户参数**：顶层参数（参数名仅含一个反斜杠，即 `PartName\ParamName`），并合并"几何图形集"下参数。
- **三维标注**：遍历 `AnnotationSets`，收集标注集/标注名/标注文本。
- **截图**：零件整机截图（800×600 白底无结构树）；`--shots` 时再逐个截三维标注。

### 5. Excel 报告（四个页）

| 页 | 内容 |
| --- | --- |
| 测量结果 | 每零件一行：体积/表面积/密度/质量/重量/包络体长宽高/备注/整机截图 |
| 用户参数 | 每个零件的用户自定义参数列表（文件/参数名/参数值） |
| 参数汇总 | 列头=参数名，行=零件，单元格=参数值（便于横向对比） |
| 三维标注 | 按零件号分页；首行"全部标注（选中所有）"整体截图，其后逐个标注截图 |

### 6. 截图机制

CATIA 的 3D 视口是 OpenGL，截图有多种兜底策略（按成功率择优）：

1. `Viewer.CaptureToFile`（视口直出，优先）；
2. `ImageGrab` 屏幕抓取，连抓多帧取"白底+模型"最丰富的一帧；
3. `PrintWindow` 兜底（flag 2→1→0 降级）。

截图前会：窗口置 800×600 并临时置顶 → 零件居中（FitAllIn）→ 隐藏结构树 → 切白色背景 → 等待渲染 → 截图 → 统一为 800×600 白底。已按规格且非空白的截图会跳过（支持断点续跑）。

### 7. 装配体（.CATProduct）

- 递归统计零件实例，体积/质量按可解析的零件几何体求和。
- 打开装配体前会设置 `CATIA.FileSearchDirectories` 为文件所在目录，使 CATIA 能自动按目录加载同目录下的子 `.CATPart`（否则易报"零件文件缺失/未加载"）。
- 子零件文件必须存在且可被 CATIA 搜索到；若仍缺失，报告会列出缺失/未加载的子项数量。
- 装配体级包络体未计算（可对内部零件逐一测量后在 Excel 汇总）。

## 二、VBA 宏（单零件，CATIA 内运行）

一个在 CATIA V5 中运行的宏，一键测量当前打开的单个零件（`.CATPart`）：

| 测量项 | 说明 | 输出单位 |
| --- | --- | --- |
| 体积 | SPAWorkbench.Measurable 精确测量 | m³ / cm³ |
| 表面积 | 零件全部表面面积之和 | m² / cm² |
| 重量 | 质量 = 体积 × 密度（密度由你输入，默认钢 7.85） | kg / g |
| 重量（力） | 质量 × 9.80665 | N |
| 包络体长 / 宽 / 高 | 与世界坐标系对齐的 AABB（沿 X / Y / Z） | mm / m |

### 使用方法（CATIA V5）

1. 在 CATIA 中打开要测量的零件（`.CATPart`）。
2. 菜单：**工具 → 宏 → 宏…**（快捷键 `Alt+F8`）。
3. 若宏列表中找不到本宏：
   - 点击 **库（Libraries）…** → **创建（Create）…** → 类型选 **目录（Directory）**（或"VBA 项目"）→ 选择本文件夹所在的目录；
   - 回到宏列表，找到 `MeasurePart`。
4. 选中 `MeasurePart` → 点击 **运行（Run）**。
5. 弹出密度输入框：输入材料密度（单位 g/cm³，默认 7.85 为钢），点确定。
6. 查看测量结果弹窗；同时会在零件同目录自动生成 `零件名_测量结果.txt` 报告文件。

> 另一种运行方式：菜单 **工具 → 宏 → Visual Basic 编辑器**（`Alt+F11`），新建模块并把 `MeasurePart.CATScript` 的内容粘贴进去，再运行 `CATMain`。

### 常用材料密度参考（g/cm³）

| 材料 | 密度 | 材料 | 密度 |
| --- | --- | --- | --- |
| 钢 | 7.85 | 铜 | 8.9 |
| 铸铁 | 7.2 | 铝 | 2.70 |
| 不锈钢 | 7.93 | 镁合金 | 1.74 |
| 黄铜 | 8.5 | ABS 塑料 | 1.05 |
| 钛合金 | 4.5 | 水 | 1.0 |

### 工作原理（简要）

- **体积 / 表面积**：`SPAWorkbench.GetMeasurable()` 读取 `Volume`（m³）与 `Area`（m²）；先整零件测量，失败则遍历所有几何体（Body）累加。
- **重量**：质量 = 体积 × 输入密度；重量（N）= 质量（kg）× 9.80665。
- **包络体**：遍历零件内所有几何特征（Shape）逐个调用 `GetBoundingBox` 获取各特征包围盒，再合并取并集得到整零件 AABB；尺寸按文档长度单位换算为 mm。

### 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 提示"请先打开零件文档" | 先打开 `.CATPart` 再运行宏；装配体（`.CATProduct`）暂不支持 |
| 测量失败（体积/表面积无法计算） | 确认零件含实体或曲面几何体；确认已加载 **SPA** 许可 |
| 包络体显示"无法计算" | 多为旧版本 `GetBoundingBox` 兼容性或零件无几何体；可换高版本或用简单实体测试 |
| 宏中中文显示乱码 | 本文件按 GBK/ANSI 保存，适用于中文版 Windows；仍乱码则用记事本"另存为 ANSI" |
| 质量/重量为 0 | 密度输入错误或零件无体积（纯曲面） |
| 宏被安全策略阻止 | 菜单：**工具 → 选项 → 常规 → 宏 → 安全性**，调为允许运行 |

## 三、已知问题 / 限制

1. **包络体疑似异常**：多几何体零件若含被放置在极远处的几何体（如镜像参考体），并集后的包围盒某方向会异常偏大（实测曾出现宽 ~24000 mm）。程序会对"某方向 >5000 mm 且远大于其余两维"的情况标记为**疑似异常**，在报告与 Excel 备注中提示"仅作参考"。如需精确包络体，应在 CATIA 中检查/清理远置几何体，或后续扩展为排除构造几何体。
2. **装配体依赖子零件文件**：若子 `.CATPart` 不在搜索目录内，体积/质量无法获取（程序会列出缺失子项数）。请确保子零件与装配体同目录或可被 CATIA 搜索到。
3. **密度需手动给定或零件已赋材质**：零件未赋材质时无法自动读取密度（CATIA 接口限制），用 `--density` 指定。
4. **包络体为 AABB**（沿坐标系方向），非基于惯量主轴的"最小"包围盒（OBB）。
5. **截图依赖 CATIA 前台渲染**：截图需 CATIA 窗口可见并完成渲染，后台/最小化或显卡驱动不兼容时可能截到空白（已有多策略兜底与空白检测）。
6. **包络体排除阈值**：远置几何体判据为"离质心距离 >5 倍自身最大边长"，对正常多实体零件（各体聚集在原点附近）不误排；若某真实零件本就含分离的大实体，可能被误排，此时以 Excel 备注/控制台"排除 N 个远置几何体"为准核对。

## 四、在 test/ 上批量测量（需在装有 CATIA 的机器执行）

```bash
# 1) 测量全部 127 个零件, 生成文本/JSON/Excel
python measure_catia.py --dir test

# 2) (可选) 生成三维标注逐个截图并写回 Excel
python measure_catia.py --dir test --shots

# 或用界面: python measure_catia.py --gui
```

输出位于 `test/`：`测量结果.txt`、`results.json`、`测量结果.xlsx`（及 `零件截图/`、`三维标注截图/`）。
